# Cohort Learning Labs

Cohort Learning Labs helps professional teams adopt AI thoughtfully through collaborative learning, practical implementation, and responsible human oversight.

Production: [https://www.cohortlearninglabs.org](https://www.cohortlearninglabs.org)

## Application

This repository contains the Cohort Learning Labs website, built as a Next.js 16 application with TypeScript and Tailwind CSS.

### Routes

`lib/routes.ts` is the route inventory. The header navigation, the footer page list and the generated sitemap all read it, so adding or renaming a public page is a single edit there.

Two routes are deliberately kept out of that inventory. `/our-approach` and `/values` remain reachable by direct link but call `notFound()` and set `robots: { index: false }`; `scripts/validate-site.mjs` fails the build if either is added to navigation or loses its containment.

Legacy paths permanently redirect (HTTP 308) rather than 404, so crawlers treat the destination as canonical:

- `/the-question` → `/services`
- `/pricing` → `/contact`
- `/where-it-applies`, `/writing`, and `/illustrative-engagement` → `/`
- `/about-elie` and `/testimonials` → `/about`

`/sitemap.xml` and `/robots.txt` are generated by `app/sitemap.ts` and `app/robots.ts`. Do not add static files of those names to `public/` — they would shadow the generated routes, and the validator rejects them.

Blog and ebook materials are unavailable while their content and publishing details are reviewed; their route stubs have been removed, so those paths now 404 through the standard not-found page. Newsletter APIs are not implemented. Consultations are booked through a Calendly embed on `/contact#book`; email remains a fallback.

## Local development

Requirements: a current Node.js release supported by Next.js 16 and npm.

```bash
npm ci
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Verification

The same four commands the CI workflow runs, in the same order:

```bash
npm run check         # structural invariants (scripts/validate-site.mjs)
npm run lint          # eslint, next/core-web-vitals + next/typescript
npm run format:check  # prettier
npm run build
```

`npm run format` rewrites files in place.

## Deployment

Consultations book through [Calendly](https://calendly.com/andrea-schulman-coaching/consultation-with-elie). Override that URL with `NEXT_PUBLIC_CALENDLY_URL` in `.env.local` or Vercel if it changes. Connect the event to Google Calendar in Calendly so only free slots appear.

The GitHub repository is connected to Vercel. Pull requests may receive automatic preview deployments. Changes merged to `main` are deployed through the connected production workflow.

The repository is owned by the Humans-Benefiting-from-AI organization. The main branch is protected by the Protect main ruleset, so changes require a pull request and a passing Vercel check.

Do not trigger a manual production deployment for ordinary content changes.
