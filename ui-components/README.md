# UI Components System

A quick and easy system for creating, previewing, and iterating on UI components.

## Quick Start

### Method 1: Use the Node.js Script
```bash
cd ui-components
node create-component.js "My New Component"
```

### Method 2: Ask Claude to Generate
Just tell me:
- Component name
- What it should look like/do
- Any specific styling requirements

I'll create the HTML file instantly for you to preview.

## Files Structure

```
ui-components/
├── README.md                           # This file
├── component-template.html             # Base template
├── create-component.js                # Component generator
├── header-example.html                # Example: Your header component
├── two-tier-navigation.html           # Complex navigation with mega menus
├── two-tier-navigation-simplified.html # Clean navigation with regular dropdowns
├── button-variants.html               # Complete button system
└── [your-components].html             # Generated components
```

## How to Use

1. **Create Component**: Use script or ask Claude
2. **Preview**: Open the `.html` file in your browser
3. **Iterate**: Ask Claude to modify specific parts
4. **Extract**: Copy HTML/CSS to your main project when ready

## Example Components Available

- `header-example.html` - Responsive header matching your site style
- `two-tier-navigation.html` - Complex navigation with mega menus and utility bar
- `two-tier-navigation-simplified.html` - Clean navigation with regular dropdowns only
- `button-variants.html` - Complete button system with all variants and states
